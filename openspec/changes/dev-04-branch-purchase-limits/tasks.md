## 1. Модель и настройки

- [ ] 1.1 Создать CFE/source set extensions/BranchPurchaseLimits с префиксом; через Юнику уточнить типовые суммы реализаций/возвратов и управленческую валюту.
- [ ] 1.2 Создать документ лимита со строками организаций-филиалов, нормализованным месяцем, состояниями и неотрицательными суммами.
- [ ] 1.3 Добавить филиал в участвующие строки реализаций/возвратов и движения; уточнить критерий участия/допустимые филиалы и подготовку старых движений, не создавать соответствие контрагент–филиал.
- [ ] 1.4 Создать роль утверждения и регистр уникального утверждённого лимита по головной организации/месяцу.

## 2. Жизненный цикл

- [ ] 2.1 Реализовать серверные проверки обязательных полей, дубликатов филиалов, отрицательных сумм и запрета головной организации как собственного филиала.
- [ ] 2.2 Реализовать ручное заполнение и копирование утверждённого документа предыдущего месяца в новый черновик без изменения источника.
- [ ] 2.3 Реализовать атомарное утверждение под блокировкой ключа организации/месяца и проверку прав текущего пользователя.
- [ ] 2.4 Защитить утверждённый документ от правки всех данных, снятия утверждения, заполнения, пометки/физического удаления и прямой записи; заблокировать форму.

## 3. Факт и отчёт

- [ ] 3.1 Реализовать выборку проведённых товарных реализаций головной организации филиалам по сохранённым в строках/движениях филиалам; запретить проведение участвующей строки без филиала.
- [ ] 3.2 Реализовать отрицательные возвраты на дату возврата, включая прошлый месяц продажи, смешанные и без основания; обеспечить ручной филиал каждой такой строки, уточнить ограничения и обычный перенос из основания.
- [ ] 3.3 Получить суммы без НДС после всех скидок по ставке строки; уточнить курс/дату/округление управленческого пересчёта и подтвердить их на валютной операции.
- [ ] 3.4 Создать СКД с отдельными агрегатами плана/факта, динамическими датами, полной совокупностью филиалов, итоговым процентом и «н/д».
- [ ] 3.5 Оформить отчёт по XLSX без переноса пропущенной даты, ошибочного знака возврата, нулевого процента и демонстрационных отдельных оснований филиалов.

## 4. Валидация и приёмка

- [ ] 4.1 Выполнить unica.check изменённых объектов/BSL и git diff --check; прочитать unica.run {} и собрать CFE по текущему контракту.
- [ ] 4.2 Проверить пример Востока на явно заданных суммах без НДС после скидок: 1 500 000 план, 1 300 000 факт, 86,7%, три даты; проверить возврат и отмену проведения.
- [ ] 4.3 Подтвердить режим/ставки исходных сумм и пересчитать журнал XLSX без НДС; проверить 120 000 с НДС 20% → 100 000, разные ставки, 27.11, отрицательную 22.12, нулевой план и сверку колонок.
- [ ] 4.4 Проверить прямую запись/удаление утверждённого лимита, два одновременных утверждения одного ключа, копирование без источника и дубли филиалов.
- [ ] 4.5 Проверить несколько месяцев/организаций, посторонних покупателей, иностранную валюту и построчные филиалы одного контрагента, возвраты без основания и неизменность истории после правки карточки; сохранить результаты и скриншоты.
- [ ] 4.6 Подготовить порядок начальной настройки, утверждения, резервирования дополнительных данных и отката без снятия утверждения.
