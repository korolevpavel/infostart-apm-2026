# Самостоятельный учебный кейс: анализ ЗНР через grill-with-docs

## Цель и границы

- Уточнить требования через интервью с пользователем и документировать согласованные термины и решения.
- Это самостоятельный учебный кейс, не часть сравнительных прогонов OpenSpec.
- Использовать только материалы этой папки, без результатов соседних экспериментов.
- Документы и диалог вести на русском языке.

## Работа с требованиями

- Факты из ЗНР и исходников отделять от рекомендаций и решений пользователя.
- Ответы на бизнес-вопросы не придумывать.
- Рекомендации не считать принятыми без ответа пользователя.

## Работа с исходниками

- Исходники разрешено читать обычным поиском.
- Unica и OpenSpec для этого кейса не использовать.
- Исходники не изменять, сборку и базу не запускать, реализацию не начинать.

## Коммиты

В коммиты, созданные при участии Codex, добавлять трейлер:

```text
Co-Authored-By: codex <codex@openai.com>
```
