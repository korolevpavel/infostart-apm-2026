# Самостоятельный анализ ЗНР через grill-with-docs

Учебный кейс уточнения требований к контролю минимальной цены продажи в заказе клиента. Кейс самостоятельный и не входит в сравнительные прогоны OpenSpec.

## Материалы и результаты

- [ЗНР.docx](ЗНР.docx) — исходное задание DEV-1C-05.
- [AGENTS.md](AGENTS.md) — границы работы и правила анализа.
- [.agents/skills/](.agents/skills/) — использованные локальные скиллы `grill-with-docs`, `grilling` и `domain-modeling`.
- [GLOSSARY.md](GLOSSARY.md) — согласованные термины.
- [docs/analysis.md](docs/analysis.md) — технические факты, дерево интервью и решения Q1–Q32.
- [docs/adr/0001-historical-control-price.md](docs/adr/0001-historical-control-price.md) — решение о сохранении исторического порога.
- [docs/final-review.md](docs/final-review.md) — подтверждённая итоговая сверка.
- [docs/acceptance.md](docs/acceptance.md) — 30 сценариев и 21 числовой пример приёмки.
