# infostart-apm-2026

Учебный комплект к демонстрации анализа заданий 1С с помощью агентов, OpenSpec, Юники и LLM Wiki.

## Что внутри

- [Исходные задания и макеты](.local/inbox/): шесть DOCX и три XLSX.
- [OpenSpec](openspec/inbox-development-index.md): исследование и предложения по шести ЗНР, вопросы, сценарии и задачи.
- [LLM Wiki](llm-wiki/README.md): оригиналы учебных переписок в `raw/`, конспекты и тематические страницы в `wiki/`.
- [Дашборд](sites/znr-overview/README.md): обзор состояния ЗНР со светлой и тёмной темами. Скачайте репозиторий и откройте `sites/znr-overview/dashboard.html` в браузере.
- [Сравнение девяти экспериментов OpenSpec](sites/openspec-experiments/README.md): офлайн-дашборд с рейтингом качества, доказательствами, затратами и 36 попарными сравнениями. Скачайте `sites/openspec-experiments/dashboard.html` и откройте в браузере.
- [Материалы всех девяти прогонов](experiments/openspec/README.md): ЗНР, спецификации, отчёты с замерами, правила, сохранённые переписки и журналы координации. Исходники УТ и сырые журналы Codex не публикуются.
- [Самостоятельный анализ ЗНР через grill-with-docs](experiments/grill-with-docs/): уточнение требований к контролю минимальной цены продажи через интервью, словарь, решения и примеры приёмки. Анализ завершён, требования согласованы; реализация не начиналась. Кейс ведётся отдельно от сравнительных прогонов OpenSpec.
- `.codex/skills/`, `AGENTS.md`, `.gitattributes`, `.gitignore` и `v8project.yaml`: настройки и инструкции процесса.

Участники переписок и обсуждаемые решения вымышлены. Материалы показывают процесс уточнения требований; готовность документов не означает согласование или завершение разработки.

## Границы комплекта

В GitHub-версию не включены исходники типовой конфигурации УТ11 (`src/`) — ни в текущем дереве, ни в переданной истории. Файлов выгрузки инфобазы (`.dt`) в комплекте нет. Для работы с Юникой нужна собственная легально полученная УТ11 11.6.2.68: разместите Designer XML в локальной папке `src/`, указанной в `v8project.yaml`. Папка исключена из новых коммитов.

Настройки подключения храните в игнорируемом `v8project.local.yaml`. Базы, сборки, SRT, персональные настройки и привязка аккаунта Sites не публикуются.

## История

GitHub-репозиторий содержит отфильтрованную историю подготовки материалов. Коммиты, содержавшие только исходники конфигурации, опущены; хеши оставшихся коммитов изменились. Полная исходная история остаётся в локальном рабочем репозитории. Обновлять GitHub следует через такую же отдельную фильтрованную копию: обычный push локальной истории вернёт исключённые исходники.

## Обновление дашборда

Нужны Python 3, OpenSpec CLI и Node.js для проверки:

```sh
python3 sites/znr-overview/build_snapshot.py
node sites/znr-overview/verify.mjs
```

После сборки включайте обновлённый `dashboard.html` в коммит. Каталог `dist/` пересоздаётся и не версионируется.

## GitHub Pages: два дашборда

С 12.11.2026 репозиторий публичный, GitHub Pages включён. Участники могут открыть [обзор ЗНР](https://korolevpavel.github.io/infostart-apm-2026/) и [сравнение девяти экспериментов OpenSpec](https://korolevpavel.github.io/infostart-apm-2026/experiments/) прямо в браузере.

Workflow **Publish dashboards** собирает только два готовых HTML-файла через `sites/build_pages.py`. Изменение любого из них в `main` запускает публикацию при выполнении условий workflow. Прочие файлы репозитория не копируются в Pages.

Публикация выполняется через GitHub Actions. Первый [запуск Publish dashboards](https://github.com/korolevpavel/infostart-apm-2026/actions/runs/43202651562) завершился успешно. Оба дашборда и каталог материалов проверены без авторизации, серверы вернули HTTP 200. [Инструкция обновления](sites/znr-overview/README.md#github-pages).
