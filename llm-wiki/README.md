# LLM Wiki

Локальное хранилище по [идее Andrej Karpathy](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).

Начало работы: [индекс](wiki/index.md). Правила для агента: [AGENTS.md](AGENTS.md).

1. Поместите материалы в `raw/`.
2. Попросите: «Обработай источник `llm-wiki/raw/имя-файла`».
3. Задавайте вопросы по wiki. Для проверки попросите: «Проверь llm-wiki на противоречия и битые ссылки».

Папку можно открыть как хранилище в Obsidian. Установка плагинов не требуется. `raw/` с учебными оригиналами и страницы wiki версионируются вместе с проектом. Не добавляйте сюда реальные конфиденциальные материалы.

Обработаны все 18 материалов из `raw/`: учебные переписки по шести темам. Конспекты, тематические обобщения и открытые вопросы доступны в [индексе](wiki/index.md). Участники и решения вымышлены; это не реальное согласование проекта.
