## Расхождения с XLSX

| Место | Наблюдение | Решение для предложения |
| --- | --- | --- |
| Печатная форма!G12 | D12*F12*1.1 даёт 56,1 вместо 51 кг | Убрать необоснованные 10%; эталон ТЗ — общий вес 200 кг |
| J11:J15 | Класс считается по I+H, то есть после позиции | Считать только по накопленной доле ДО позиции, интервалы [0;50), [50;75), [75;90), [90;100] |
| C10 и K10 | Группа товара и закупочная цена | Не заменяют обязательную Характеристику; закупочная цена не входит в печать по ТЗ |
| G16, свод классов | Закэшированы результаты ошибочных формул | Пересчитать по данным, не переносить значения 205,1 и A/B/C/D/D |

## Выбор подхода

Внешняя печатная форма БСП соответствует прямому требованию и сохраняет поддержку. Встроенный отчёт и изменение типового менеджера не нужны.
Расчётная позиция — пара (номенклатура, характеристика), строки вывода дополнительно разбиваются по единице. Класс назначается один раз общей позиции; масса подстрок не дублируется в итоге.

```text
Реализация → проверка массы → агрегирование пары → сортировка
           → доля до позиции → класс → подстроки единиц → комплект печати
```

## Допущения и проверки реализации

Выбран документ реализации, что подтверждается подписью в макете. Печать перечитывает текущие сохранённые данные; незаписанные изменения сначала сохраняются стандартным способом.
Источник массы — масса единицы хранения с переводом в кг; упаковка определяет количество таких единиц. Использование отдельной массы брутто потребовало бы изменения бизнес-правила.
Нулевая/отсутствующая масса или некорректный коэффициент не превращаются в класс D. Пустой документ не порождает деление на ноль.
Контрольный пример: 64, 51, 39, 29, 17 → 200 кг → A, A, B, C, D.
