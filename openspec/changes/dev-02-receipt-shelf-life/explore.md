## Проверенные факты УТ через Юнику

- `main:Catalog.СерииНоменклатуры.Attribute` содержит ДатаПроизводства и ГоденДо, оба дата/время; отдельного реквизита полного срока в просмотренной полной коллекции нет.
- `main:Catalog.СоглашенияСПоставщиками` — «Соглашения об условиях закупок», поддержка locked; расширение должно заимствовать объект.

- Прочитан `main:Document.ПриобретениеТоваровУслуг.Module.Object.Method.ОбработкаПроведения.Body`, строки 886–899. Проведение делегирует работу ПроведениеДокументов и локализации; проверку следует подключать перед типовыми движениями и возвращать Отказ.

## Выбор подхода

Повторно используем ДатаПроизводства с представлением «Дата изготовления». В расширении добавляем целое положительное число дней; ГоденДо синхронизируем с вычисленной датой окончания, чтобы два значения не противоречили друг другу.
Процент — функция от даты документа, не постоянный реквизит серии. На форме серии нужен параметр «На дату»; при открытии из приобретения передаётся дата этого документа.

```text
Соглашение → минимум
Приобретение → дата + все серии → дата производства + дни → остаток
                                              ↓
                                  общий Отказ до движений
```

## Риски и принятые допущения

- Даты нормализуются до начала календарного дня; время суток не сокращает остаток.
- Отсутствующее соглашение/ненастроенный порог нельзя молча трактовать как 0%. Предлагается отдельный признак настройки порога: явно заданные 0% допустимы, отрицательный остаток всё равно запрещён.
- Товары, где политика серий предполагает указание серии только на складе, требуют маршрута проверки с фактическими сериями. Реализация должна подтвердить доступность серий до проведения приобретения; отсутствие обязательных серий означает отказ с пояснением, а не пропуск проверки.
- Изменение серии не перепроводит историю автоматически; при следующем проведении данные проверяются заново. Для старых серий нужна явная подготовка данных без выдумывания даты производства.
- Числовые эталоны: срок 120 дней, порог 75%, через 28 дней 92/120 = 76,7%; через 35 дней 85/120 = 70,8%. Сравнение производится до округления.
