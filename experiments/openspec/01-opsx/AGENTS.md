# Правила эксперимента

- Это эксперимент по подготовке спецификации на основе `ЗНР.docx`.
- Используй только материалы этой папки. Не читай соседние папки, исходники конфигурации и результаты предыдущих экспериментов.
- Не используй Unica и другие специализированные скиллы и инструменты 1С.
- Документы OpenSpec пиши на русском языке.
- Пока не создавай предложение изменения и не начинай реализацию.
- В коммиты с твоим участием добавляй трейлер:

  `Co-Authored-By: codex <codex@openai.com>`
