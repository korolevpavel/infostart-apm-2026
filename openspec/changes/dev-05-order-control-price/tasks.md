- [ ] 1.2 Создать CFE/source set extensions/OrderControlPrice, заимствовать заказ и обе формы, добавить контрольную цену и служебный снимок строки, причину в каждой товарной строке.
- [ ] 1.3 Подготовить настройку устойчивых ссылок на виды «Закупочная» и «Контрольная цена», проверить формулу закупочная /0,91 (91 → 100) и отсутствие неоднозначных видов.

## 2. Снимок и интеграция

- [ ] 2.1 Реализовать серверное получение контрольного вида с проверкой закупочной базы и приведением к валюте/единице/НДС заказа.
- [ ] 2.2 Реализовать ключ происхождения снимка и сравнение с сохранённой версией: запрет подмены, пересчёт новых/изменённых ключей, сохранение истории для аудита; уточнить её состав/момент/хранилище, не использовать снимок как разрешение продажи.
- [ ] 2.3 Подключить сервис при ручном вводе, смене номенклатуры/характеристики/упаковки и обработке подбора обычной формы.
- [ ] 2.4 Подключить тот же сервис в самообслуживании, программном заполнении и копировании; очищать у копии причины во всех строках.
- [ ] 2.5 В форме пересчитывать затронутые строки; при каждом проведении/перепроведении пересчитывать все проверяемые строки, включая старые заказы, по ценам на отдельно уточнённую дату проведения.

## 3. Контроль проведения

- [ ] 3.1 Определить итоговую цену после скидок без их повторного вычитания, применить единый режим НДС/валюты/единицы и типовую точность.
- [ ] 3.2 Подключить обязательный серверный контроль проведения для всех интерфейсов, прямой записи и загрузки; пропускать только отменённые товарные строки.
- [ ] 3.3 Проверять актуальное полномочие при отклонении, уточнить роль/формат/реакцию и требовать содержательную причину каждой строки ниже порога, сохраняя её в строке; отсутствие источника не обходится ролью.
- [ ] 3.4 Выводить сообщения с товаром, фактической/контрольной ценами и недостающей настройкой, сохраняя уже установленный типовой Отказ.
