# Правила седьмого эксперимента с OpenSpec

- Эксперимент проводится через отдельные чаты: координатор, аналитик, исследователь и критик. Субагентов не использовать.
- Координатор передаёт задания и результаты между чатами, объединяет выводы и записывает итоговые документы. Аналитик, исследователь и критик работают только на чтение.
- Использовать только материалы этой папки. Не обращаться к соседним экспериментам и их истории.
- Исследовать исходники через Unica. Каждый переход к обычному чтению файлов явно отмечать.
- Неустановленные бизнес-правила оставлять открытыми вопросами; не подменять их предположениями.
- Документы писать на русском языке, сохраняя обязательный синтаксис OpenSpec, включая структурные заголовки и ключевые слова SHALL/MUST.
- Не изменять исходники. Не запускать сборку, обновление или информационную базу. Реализацию не начинать.
- Во все коммиты, созданные при участии Codex, добавлять трейлер:

  ```text
  Co-Authored-By: codex <codex@openai.com>
  ```
