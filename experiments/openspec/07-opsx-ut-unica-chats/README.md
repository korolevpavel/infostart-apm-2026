## Повторение опыта

Начинайте с отдельной чистой папки: скопируйте ЗНР, при необходимости добавьте собственные исходники УТ в `src/`, затем повторите запросы из переписки. Чтение готовых результатов заранее меняет условия эксперимента. Настройки и скиллы сохранены для изучения исторического окружения OpenSpec 1.16.1.

Исходники УТ, локальные журналы Codex и история Git этого прогона не опубликованы. Упоминания строк исходников и идентификаторов чатов сохранены как свидетельства; они не предоставляют доступ к локальной базе или аккаунту автора.
