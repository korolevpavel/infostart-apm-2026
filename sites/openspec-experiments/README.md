# Сравнение девяти экспериментов OpenSpec

Интерактивный дашборд сравнивает качество и проработанность спецификаций, открытых вопросов, технических оснований и задач, а также время, токены и денежную оценку по единому тарифу. Содержит отдельный разбор пар 06 ↔ 08 и 07 ↔ 09 — с Unica и без неё.

## GitHub Pages

Сборка Pages подготовлена для публикации экспериментов по пути `/experiments/`; обзор ЗНР остаётся в корне сайта. `sites/build_pages.py` копирует только два готовых HTML-файла, без исходников проекта и настроек. По решению автора публикация отложена до открытия текущего репозитория: тариф не поддерживает Pages для приватного проекта. После открытия включите источник GitHub Actions в настройках Pages и запустите workflow Publish dashboards.

## Открыть офлайн

1. [Скачайте dashboard.html](https://github.com/korolevpavel/infostart-apm-2026/raw/refs/heads/main/sites/openspec-experiments/dashboard.html) или скачайте репозиторий целиком.
2. Откройте скачанный файл в обычном браузере.

Установка и подключение к интернету не нужны. Стили, логика, данные девяти прогонов, 59 документов для чтения и скачиваемые аналитические отчёты встроены в один файл. Фильтры, 36 попарных сравнений и переключатель тарифов работают локально. На странице файла в GitHub отображается исходный HTML; для работы дашборда его нужно скачать и открыть.

Полные [материалы девяти прогонов](../../experiments/openspec/README.md) опубликованы отдельно: документы OpenSpec, отчёты, видимые переписки и журналы координации. Сырые журналы Codex, полная выгрузка УТ, настройки подключения и привязка аккаунта Sites не публикуются. Внутри дашборда есть выдержки и тексты исследовательских артефактов, агрегированные метрики и границы их интерпретации. Это отдельный материал от [обзора ЗНР](../znr-overview/README.md).

Снимок обновлён 08.11.2026. Качество оценивается по документам одного прогона каждого подхода; рейтинг не доказывает общее превосходство метода. Денежные значения — нормализация по указанному в дашборде тарифу, а не фактическое списание.
