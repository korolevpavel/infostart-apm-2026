# Правила пятого эксперимента с OpenSpec

- Это эксперимент: сначала выполни отдельное исследование через `openspec-explore` с использованием Unica, затем подготовь предложение через `openspec-propose`.
- Источники требований и сведений о конфигурации — `ЗНР.docx` и исходники УТ 11 в `src/`.
- Используй только материалы этой папки. Не читай соседние папки и результаты других экспериментов.
- Для исследования конфигурации 1С используй Unica и соответствующие скиллы. Если нужная операция недоступна, явно сообщи об этом; при переходе к обычному чтению файлов явно отмечай такой переход.
- Документы OpenSpec пиши на русском языке, сохраняя обязательный синтаксис, структурные заголовки и ключевые слова SHALL/MUST.
- На этапе подготовки папки не анализируй содержимое ЗНР и исходников, не создавай предложение изменения и не начинай реализацию. К исследованию переходи только по отдельному указанию пользователя.
- Не изменяй исходники и не запускай сборку, обновление или запуск информационной базы.
- Инициализацию проекта Unica выполняй отдельным следующим шагом по указанию пользователя.
- Актуальные скиллы OpenSpec должны находиться в `.agents/skills/`. При обнаружении старых скиллов OpenSpec в `.codex/skills/` сообщи об этом пользователю.
- В коммиты с участием Codex добавляй трейлер `Co-Authored-By: codex <codex@openai.com>`.
