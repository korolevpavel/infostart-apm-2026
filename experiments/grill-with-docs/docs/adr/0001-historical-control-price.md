# Сохранение исторической контрольной цены

Контрольная цена сохраняется в строке заказа и не обновляется из нового прайса при открытии или проведении. Пользователь принял это правило в Q1, чтобы сохранять действовавший для заказа порог, хотя повторное получение текущего прайса позволило бы проверять заказ по новым ценам. Пересчёт выполняется при изменении параметров источника цены; по Q6 к ним относится дата заказа. По Q9 новый заказ при копировании или вводе на основании получает новые пороги.

По Q12 проверяются сохранённые основания расчёта без обращения к текущему прайсу. По Q14 смена упаковки, валюты и режима НДС преобразует сохранённую исходную цену; по Q29 смена общих настроек видов цен сама по себе исторический порог не обновляет. По Q32 преобразования начинаются от исходной цены, чтобы округление отображаемого порога не накапливалось.

Решение принято пользователем в интервью; разрешения на реализацию нет.
