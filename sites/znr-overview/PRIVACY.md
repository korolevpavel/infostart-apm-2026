# Состав данных и исключения Git

Проверено 05.11.2026: исходники дашборда, локальный HTML и встроенный JSON-снимок. Проверка включала просмотр состава документов и поиск признаков ключей, паролей, токенов, адресов email и абсолютных пользовательских путей. Это проверка текущих файлов, а не гарантия отсутствия любых конфиденциальных сведений в будущих источниках.

## Что обнаружено

- Встроены полные тексты внутренних требований, технических решений, сценариев и задач. Они нужны для чтения из карточек, но сгенерированные копии не нужны в Git.
- Конспекты wiki содержат учебные имена, правила и числовые примеры. По самим источникам участники и решения вымышлены; это не подтверждённые персональные или реальные финансовые данные.
- В текущем JSON не найдены email-адреса, абсолютные пути пользователей, приватные ключи, Bearer-токены или присваивания непустых паролей/API-ключей. Пригодных учётных данных в просмотренных исходниках также не обнаружено.
- `.openai/hosting.json` содержит привязку к конкретному Site. Идентификатор не является паролем, но относится к аккаунту и не нужен для локальной сборки.
- Ранее генератор добавлял все Markdown из OpenSpec и wiki, включая журнал wiki. Такое расширение состава было избыточным.
- CSS автоматически загружал шрифт Google Fonts; браузер при этом обращался к внешнему сервису.

## Что изменено

В корневом `.gitignore` исключены локальные `dist/`, `dashboard.html`, `.openai/`, временные каталоги Sites и Python-кэш. В Git остаются исходники `web/`, генератор, проверочный скрипт и эта документация. Выходные файлы сохранены локально, история уже отслеживаемых OpenSpec/wiki не переписывается.

Генератор включает только документы шести выбранных изменений, два общих индекса/сверку OpenSpec и тематические ветви wiki. Журнал, архивы и другие изменения OpenSpec автоматически не импортируются. Ссылки за границу рабочей папки и скрытые пути не загружаются. При добавлении новых источников в тематические ветви wiki состав снимка нужно пересмотреть.

Автоматическая загрузка внешнего шрифта убрана, персональные инициалы в интерфейсе заменены обозначением УТ. Пароли, настройки инфобазы, оригинальные DOCX/XLSX/PNG, токены и привязка Sites в HTML не встраиваются. Относительные ссылки на оригиналы могут быть видны как указатели, но содержимое оригиналов не загружается.

## Практические границы

`dashboard.html`, `dist/data.js`, `dist/snapshot.json` и экспорт JSON по кнопке содержат внутренние сведения о проекте. Их исключение из Git не делает их общедоступными и не отменяет проверку состава перед передачей. Применяемые исходные OpenSpec и wiki уже отдельно версионируются в этом репозитории; эта правка не меняет их режим доступа.

Дашборд не опубликован. Новая передача во внешний Sites-репозиторий не выполнялась. Из внешних адресов в документах могут оставаться обычные ссылки; сами по себе они не вызывают автоматических сетевых запросов.
